# Privacy Policy

Last updated: 2026-08-10

Maple Launch Copy is a local-only Chrome extension.

## Data handled

The extension temporarily processes the one-time game launch argument generated in the user's browser by the official MapleStory Classic website. It converts that argument into an NGM launch command and writes the result to the user's clipboard.

## Data collection and sharing

- No account password is read.
- No launch argument is transmitted to the developer or any third party.
- No launch argument, browsing history, analytics, telemetry, or personal data is stored.
- No remote server is used by this extension.

## Site access

The extension is restricted to `https://maplestoryclassic.beanfun.com/*`.

## Clipboard access

The `clipboardWrite` permission is used only to place the converted launch command in the user's clipboard after the user completes the official game-account selection flow.

## Contact

Questions and security reports may be submitted through this GitHub repository's Issues page. Do not include a launch argument, access token, password, screenshot containing credentials, or other authentication information in an issue.
